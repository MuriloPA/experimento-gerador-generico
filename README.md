# Exemplo — Projeto de Teste do Experimento (Sprint 5)

Aplicação mínima, sem dependências externas, usada como base fixa nas
três condições do experimento (deploy manual, gerador genérico, ferramenta
proposta). Mantida idêntica entre condições para não introduzir variável
de confusão.

## Comandos
- `npm install` — instala dependências (nenhuma, além do Node embutido)
- `npm test` — roda os 3 testes com o test runner nativo do Node
- `npm run build` — simula uma build (copia o arquivo para dist/)
